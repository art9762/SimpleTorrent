# Что готово и что осталось

SimpleTorrent — личная однопользовательская очередь для домашнего сервера. Основной сценарий: добавить `.torrent` или v1 magnet, дождаться готовности и забрать файлы/ZIP. Для `.torrent` действует предварительная проверка метаданных и путей; для magnet — ограниченный разбор ссылки и честное состояние неизвестных метаданных.

## Реализовано

- `.torrent` v1/гибридный и magnet с v1 infohash, общая защита от дублей.
- Ожидание метаданных без фиктивной готовности, фильтры, пауза/продолжение/удаление.
- Готовые отдельные файлы, HTTP Range и потоковый ZIP.
- Защищённая сессия, CSRF/Origin, лимиты входа и входных данных.
- Резервирование известного оставшегося объёма и аварийная пауза при нехватке места.
- Проверка повторяющихся и конфликтующих путей `.torrent` в legacy/UTF-8 вариантах.

## Следующие задачи

| Направление | Что требуется для законченного результата |
| --- | --- |
| Чистый BitTorrent v2 | BEP 52, SHA-256 идентификаторы и совместимость API/хранилища; валидные и повреждённые fixtures, без публичного swarm в тестах. |
| Выбор части файлов | Согласовать wanted-файлы с резервированием места, прогрессом, готовностью и ZIP; состояние должно сохраняться после рестарта. |
| RSS | Добавить сохранённые подписки, ограниченный polling и защиту от повторных добавлений; предусмотреть ошибки фида и тесты локального HTTP. |
| Несколько пользователей | Аккаунты и владение записями/файлами; изоляция должна проверяться во всех download, settings и mutation-маршрутах. |
| Строгий допуск magnet после метаданных | Проверить возможность metadata-only режима в поддерживаемых версиях Transmission, затем разрешать содержимое только после проверки размера и структуры. Сейчас guard реагирует раз в 5 секунд. |
| Докачка ZIP | Сейчас Range работает только у отдельных файлов; для ZIP нужен отдельный стабильный контракт представления. |

## Что ещё нужно измерить

Перед реальной эксплуатацией на Raspberry Pi стоит проверить длительную очередь, отключения питания/сети, восстановление после перезапуска и скорость SSD/SD/Wi-Fi. Сборка и синтетические тесты не измеряют эти свойства.

В этой доработке не запускались публичные трекеры, реальные magnet/swarm-сессии или скачивание пользовательского содержимого. Обмен метаданными с настоящими пирами остаётся отдельной проверкой. [Подробная граница проверок](validation/2026-10-23-magnet.md).
