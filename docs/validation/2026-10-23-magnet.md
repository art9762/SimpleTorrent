## Граница доказательств

Локальный `transmission-daemon` отсутствует; Docker CLI установлен, но локальный Docker daemon недоступен. Поэтому настоящий daemon/restart и контейнерные проверки локально не запускались. В GitHub Actions предусмотрены integration, browser и container jobs; их актуальный результат виден в checks PR.

Добавлен opt-in тест magnet с настоящим Transmission: синтетический infohash без трекеров/пиров, DHT/PEX/LPD/UPnP выключены, проверяются ожидание, пауза и сохранение очереди после рестарта. Он не скачивает содержимое. Отдельный прежний integration-тест использует собственный loopback webseed и проверяет байты/ZIP.

Ни один локальный тест не обращался к публичным трекерам или чужим файлам. Обмен magnet-метаданными с настоящим BitTorrent-пиром, реальная скорость, память/температура Raspberry Pi и длительное хранение пока не измерялись.

## Ограничение дискового допуска

Размер magnet заранее неизвестен; поле `xl` не считается достоверным размером. После метаданных оставшийся объём попадает в резерв очереди. Guard раз в 5 секунд останавливает незавершённые активные задачи, если места не хватает с учётом резерва. Между метаданными и очередной проверкой Transmission может начать передачу содержимого. [Следующая задача для строгого допуска](../REMAINING_WORK.md).
