# Работа над SimpleTorrent

Для локального запуска и описания модулей смотрите [docs/development.md](docs/development.md).

Перед отправкой изменений:

```bash
pip install -r requirements-dev.txt
pytest -q
node --check app/static/app.js
python -m compileall -q app scripts
```

Если меняется RPC или выдача файлов, запустите интеграционный тест с установленным Transmission:

```bash
ST_INTEGRATION=1 pytest -q tests/test_integration.py
```

Проверяйте UI на телефоне и компьютере, в обеих темах. Используйте реальные API-состояния: загрузка, пустой список, ошибка сети, пауза, готовый файл. Не добавляйте демонстрационные данные в приложение. Веб-интерфейс остаётся без сборки и внешних ресурсов, чтобы сервер работал автономно и был простым в обслуживании.

Не коммитьте `.env`, файлы пользователей, runtime-конфигурацию Transmission или временные каталоги. Изменение хранилища и удаления данных должно иметь отдельный тест.

При отправке pull request опишите изменившееся поведение и выполненные проверки. Для UI приложите скриншот с тестовыми данными.
